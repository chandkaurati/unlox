# Pulse One — Responsive Product Landing Page

A responsive smartwatch product landing page built with **React, Vite, and Tailwind CSS** for the Unlox Academy Week 02 Minor Project.

## Sections included

- Responsive navigation with mobile menu
- Hero section with product artwork and CTA buttons
- Four feature cards
- Benefits / brand story section
- Three testimonial cards
- Pricing and CTA section
- Footer with contact and navigation links

## Tech stack

- React 18
- Vite
- Tailwind CSS 3
- Lucide React icons
- Custom CSS for detailed product artwork and responsive styling

## Run locally

**Requirements:** Node.js 18 or newer and npm.

```bash
npm install
npm run dev
```

Open the local URL shown in your terminal (usually `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

The production files are generated in the `dist/` directory.

## Customize

- Edit product text and features in `src/App.jsx`.
- Adjust colors and responsive styles in `src/index.css` and `tailwind.config.js`.
- The price and testimonials are sample content for a fictional product concept.
- The purchase CTA is a demo interaction only; it does not process payments.

Replace `YOUR_GITHUB_REPOSITORY_URL` with your repository URL.
