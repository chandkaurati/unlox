# Chand Kaurati — Personal Portfolio

A simple, multi-page personal portfolio built with HTML5 and CSS3.

## Pages
- `index.html` — Home
- `about.html` — About
- `skills.html` — Skills
- `projects.html` — Projects
- `contact.html` — Contact

## Run locally
Open `index.html` in your browser. No installation or build tools are required.

## Customize
Edit the HTML files to update your bio, skills, and project descriptions. All styling is in `style.css`.

## Technologies
- HTML5
- CSS3
- Git / GitHub
